# 术语总表

| 中文 | English | 核心定义 |
|---|---|---|
| [[拍卖市场理论（AMT）]] | Auction Market Theory | 把市场视为围绕价值持续进行的双向拍卖；价格在平衡中促进成交，在失衡中寻找新价值。 |
| [[平衡]] | Balance | 买卖双方在某一价值区域内持续成交，价格常表现为旋转与均值回归。 |
| [[失衡]] | Imbalance | 市场离开旧价值并朝新价值迁移，常伴随单向主动性和趋势节奏。 |
| [[价格发现]] | Price Discovery | 市场通过报价、成交和反馈寻找能促成交易的价格。 |
| [[市场订单]] | Market Order | 主动跨越点差、立即与对手方挂单成交的订单。 |
| [[限价订单]] | Limit Order | 在指定价格等待成交的被动订单，构成可见流动性的一部分。 |
| [[吸收]] | Absorption | 大量主动订单被被动流动性承接，但价格未按主动方向继续移动。 |
| [[接受]] | Acceptance | 市场在某价格区域停留并持续建立成交量/价值。 |
| [[拒绝]] | Rejection | 市场测试某区域后迅速离开，未能建立足够成交。 |
| [[成交量轮廓]] | Volume Profile | 按价格汇总成交量，用于观察价值集中与低接受区域。 |
| [[VPOC]] | Volume Point of Control | 所选样本内成交量最大的价格。 |
| [[价值区]] | Value Area | 围绕轮廓中心、覆盖预设比例成交量的价格区间。 |
| [[Composite Profile]] | Composite Profile | 把多个相关时段的 Profile 合并，用于表达更长期的平衡与历史价值。 |
| [[VWAP]] | Volume-Weighted Average Price | 成交价格按成交量加权的平均值，是动态价值与执行基准。 |
| [[标准差带]] | Standard Deviation Bands | 描述成交相对 VWAP 的分散程度，常观察 1SD 与 2SD。 |
| [[动态价值]] | Dynamic Value | 仍在发展、会随新成交变化的 VWAP 或 Profile。 |
| [[静态价值]] | Static Value | 已完成且不再随当前成交改变的历史价值，如前日轮廓。 |
| [[节奏]] | Rhythm | 市场在旋转、慢趋势、正常趋势、快速趋势之间表现出的价值建立位置、VWAP 斜率与回调深度。慢趋势通常围绕 VWAP–0.5SD，正常趋势约在 1SD，快趋势约在 1.5SD 或更远区域建立价值。 |
| [[其他周期参与者]] | Other Time Frame / OTF | 决策与持仓周期高于当前观察窗口的参与者。 |
| [[累计 Delta]] | Cumulative Delta | 按时间累加主动买入量减主动卖出量。 |
| [[Bar Delta]] | Bar Delta | 单根柱内主动买入量减主动卖出量。 |
| [[Footprint]] | Footprint Chart | 在每根柱内按价位显示 Bid/Ask 成交和相关 Delta 统计。 |
| [[Volume Bar]] | Volume Bar | 每累计固定成交量后生成新柱。 |
| [[Tick Bar]] | Tick Bar | 每累计固定笔数/价格更新后生成新柱，具体定义依平台。 |
| [[Renko]] | Renko | 按价格移动和反转阈值生成柱，弱化时间。 |
| [[被套交易者]] | Trapped Trader | 主动入场后市场未按预期延续、面临被迫平仓的参与者。 |
| [[信息风险]] | Information Risk | 较早入场时因确认信息不足而承担的风险。 |
| [[价格风险]] | Price Risk | 等待更多确认后以更差价格入场所承担的风险。 |
| [[情境]] | Context | 由历史价值、当前状态、周期、位置与事件共同构成的决策环境。 |
| [[假设]] | Hypothesis | 对市场可能路径、验证条件和失效条件的可更新陈述。 |
| [[流程评分]] | Process Score | 按准备、逻辑、执行和复盘质量评价交易。 |

> 术语统一以英文原词校验；中文是便于学习的固定译名。
