# MOC-00 课程框架与训练方法

## 核心链条

**原始成交 → 市场状态 → 多周期情境 → 可证伪假设 → 执行 → 流程复盘**

## 学习原则

1. 先用模拟与回放形成稳定流程，再评估是否进入实盘。
2. 先学会描述市场，不急于给出方向预测。
3. 微观订单流用于确认和微调，不能取代情境。
4. 用过程质量评价自己，避免被单笔盈亏误导。
