# P24 Footprint 原理：从 DOM 到成交记录

> [!summary] 一句话定位
> 证明 Footprint 是 DOM 成交数据的记录形式：DOM 会刷新，Footprint 将已经发生的主动成交保留下来。

## 本课要解决的问题

- DOM 与 Footprint 为什么是同一数据的不同展示？
- 什么信息会被记录，什么不会？

## 核心结论

- 挂单被撤掉并不等于成交；Footprint 只记录实际打印
- 买在 Ask 与卖在 Bid 反映主动性方向
- 柱内数据直到换柱才重置，便于观察一段拍卖过程
- 把 Footprint 当作记录器，而非会预测方向的指标

## 中文精读

### DOM 的瞬时性

- DOM 展示当前挂单队列和刚发生的成交，但市场移动或手动清除后，过去信息很快消失。撤掉的挂单没有成交，不应进入 Footprint 成交统计。

### Footprint 的持久性

- Footprint 把每个价格实际在 Bid/Ask 打印的成交累加到当前柱，直到满足换柱条件才开始新柱，因此相当于成交记录器。

### 验证方法

- 课程通过同时观察 DOM 与 Footprint，逐笔核对打印数字，证明 Footprint 没有创造新信息，只是保存和组织原始成交。

## 深度理解：从瞬时 DOM 到可复查记录

### 1. 一条信息的生命周期

限价单进入队列后可能被成交、撤销或移动；只有真正与市场订单匹配后，才成为成交记录并进入 Footprint。DOM 同时混合了等待成交的意图与刚发生的交易，Footprint 只保留后者。

### 2. 为什么挂单不能直接累加进 Footprint

大挂单可能在接近时撤走，也可能被隐藏数量反复补充。若把可见深度当成已成交量，会高估真实供给/需求。Footprint 的可信度来自“只记录打印”，但代价是看不到当时未成交队列的完整变化。

### 3. 并排验证实验

1. 在模拟或回放中并排打开 DOM 与 Footprint；
2. 选择一个价格，记录 Bid/Ask 的新打印；
3. 区分成交、撤单和价格移动；
4. 检查 Footprint 对实际打印的累计；
5. 等换柱后确认统计如何重置；
6. 重复到能解释每个数字来源。

### 4. 主动性不等于方向结果

Ask 成交持续增加说明主动买方更积极，但若价格始终无法上移，可能有被动卖方吸收；Bid 成交大量出现而价格不跌同理。Footprint 记录“谁在努力”，价格记录“努力有没有成功”。

## 工具边界

| Footprint 能做 | Footprint 不能单独做 |
|---|---|
| 保存逐价实际成交 | 还原所有撤单与隐藏挂单 |
| 计算主动成交统计 | 确定被动方真实总规模 |
| 支持历史回放 | 脱离价值位置预测方向 |
| 比较努力与结果 | 自动识别可交易吸收 |

## 常见误区

- ❌ 把撤单计为成交
- ❌ 认为 Footprint 是二次计算指标
- ❌ 只观察数字不区分主动方向
